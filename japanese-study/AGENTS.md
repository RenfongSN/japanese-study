# 日文複習網站：AI 開發規則

## 1. 專案目的
建立適合日文初學者使用的複習網站，提供單字、例句與即時選擇題。
網站以繁體中文說明，並能持續新增不同主題的學習單元。

## 2. 使用技術
- 使用 HTML、CSS、原生 JavaScript。
- 不使用需要安裝套件或編譯的框架。
- 網站部署於 GitHub Pages。
- 所有站內連結使用相對路徑，避免部署後找不到檔案。

## 3. 檔案結構
- index.html：首頁，列出所有單元與連結。
- lessons/：存放各單元 HTML 頁面。
- css/style.css：所有頁面共用的樣式。
- js/quiz.js：所有單元共用的選擇題功能。
- AGENTS.md：AI 開發與維護規則。
- README.md：專案簡介、使用方式與新增單元的方法。

## 4. 命名規則
- 檔名使用小寫英文字母，單字之間用連字號分隔。
- 單元檔名需反映主題，例如 greetings.html、food.html。
- 不使用中文、空格或沒有意義的檔名，例如 page2.html。

## 5. 網頁風格
- 使用白色背景、深灰色文字、藍色作為主要強調色。
- 各區塊使用卡片式排版，保留適當間距。
- 全站使用相同字體、按鈕與標題樣式。
- 主要內容寬度不超過 960px，手機上依螢幕寬度調整。
- 正文字體至少 16px。
- 互動操作使用真正的 button 元素，支援鍵盤操作。
- 答題結果以文字顯示，不能只用顏色表示對錯。

## 6. 首頁格式
首頁固定包含：
1. 網站名稱與用途說明。
2. 單元清單，每個單元顯示名稱、簡介與進入連結。
3. 簡短的使用方式。

## 7. 單元頁面格式
每個單元依下列順序呈現：
1. 返回首頁的連結。
2. 單元標題與學習目標。
3. 單字表。
4. 例句區。
5. 選擇題練習。

每個單元包含：
- 6～10 個單字。
- 每個單字附日文、假名讀音與繁體中文意思。
- 至少 3 個例句，每句附繁體中文翻譯。
- 5 題單選題，每題有 4 個選項，且只有 1 個正確答案。
- 題目只考該單元已介紹的內容。
- 日文內容需確認讀音、意思與例句用法；不確定時不能自行編造。

## 8. 選擇題功能與資料格式
- 每次顯示 1 題。
- 選擇答案後，立即顯示對錯、正確答案與簡短解釋。
- 每題只能計分 1 次，作答後鎖定選項。
- 使用「下一題」按鈕繼續。
- 完成後顯示總分，並提供「重新練習」按鈕。
- 重新練習時，清除先前答案與分數。
- 共用互動程式放在 js/quiz.js，不在各頁重複撰寫。

各單元在 HTML 中使用以下元素存放 JSON 題目資料：
<script type="application/json" id="quiz-data"></script>

每題資料固定包含：
- question：題目文字。
- options：4 個選項組成的陣列。
- answerIndex：正確選項的位置，從 0 開始計算。
- explanation：答案解釋。

題目資料格式範例：
{
  "question": "「ねこ」的中文意思是什麼？",
  "options": ["狗", "貓", "鳥", "魚"],
  "answerIndex": 1,
  "explanation": "ねこ的意思是貓。"
}

所有題目放在同一個 JSON 陣列中。
互動區使用 id="quiz" 的元素，供共用程式顯示題目。

## 9. AI 新增單元的流程
1. 閱讀本文件與既有單元。
2. 在 lessons/ 新增符合命名規則的 HTML 檔案。
3. 沿用既有單元的區塊順序與共用樣式。
4. 編寫該主題的單字、例句與題目資料。
5. 單元頁面引用 ../css/style.css 與 ../js/quiz.js。
6. 返回首頁的連結使用 ../index.html。
7. 在首頁新增對應的單元名稱、簡介與連結。
8. 更新 README.md 的單元清單。
9. 完成下方檢查後，說明新增及修改了哪些檔案。

## 10. 修改限制
- 未經要求，不刪除既有單元或功能。
- 不為單一新頁面另建一套樣式或互動程式。
- 修改共用 CSS 或 JavaScript 時，必須檢查既有單元是否正常。
- 不加入 API 金鑰、密碼或個人隱私資料。
- 若使用者要求變更專案結構，同步更新本文件與 README.md。

## 11. 完成前檢查
- 首頁能進入所有單元，各單元能返回首頁。
- 單字、讀音、翻譯及答案互相一致。
- 5 題均可作答，沒有重複計分問題。
- 全答對時顯示 5/5，全答錯時顯示 0/5。
- 重新練習後，分數與作答狀態已歸零。
- 手機寬度下沒有整頁橫向溢出。
- 瀏覽器開發者工具的 Console 沒有程式錯誤。
