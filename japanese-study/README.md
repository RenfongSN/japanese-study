# 日文小練習

## 專案簡介
這是一個提供日文初學者使用的複習網站。
每個單元包含單字、讀音、中文意思、例句及五道即時選擇題，
方便使用者閱讀後立即檢查學習成果。

## 現有單元
- 日常招呼：常見招呼與禮貌用語。
- 飲食單字：常見食物、飲料與簡單例句。

## 使用方式
開啟 index.html，選擇單元，即可開始學習。
選擇題作答後會顯示正確答案與解釋，
完成五題後顯示總分，並可重新練習。

## 使用技術
- HTML：頁面與學習內容。
- CSS：全站共用樣式及手機版排版。
- JavaScript：讀取題目、判斷答案、計分與重新練習。
- 不需要安裝套件或進行編譯。

## 專案結構
- AGENTS.md：AI 開發與維護規則。
- README.md：專案介紹與使用方式。
- index.html：首頁及單元入口。
- lessons/greetings.html：日常招呼單元。
- lessons/food.html：飲食單字單元。
- css/style.css：共用樣式。
- js/quiz.js：共用測驗功能。

## 如何新增單元
1. 請 AI 先閱讀 AGENTS.md。
2. 參考既有單元，在 lessons 資料夾新增 HTML 檔案。
3. 依照固定格式加入單字、例句與五道選擇題。
4. 引用既有的 style.css 和 quiz.js。
5. 更新首頁入口與本文件的單元清單。
6. 檢查連結、答題、計分與手機版顯示。

## 給 AI 的新增指令範例
請先閱讀 AGENTS.md，依照既有規則新增「交通工具」單元。
使用 lessons/transport.html 作為檔名，
包含八個單字、至少三個附中文翻譯的例句及五道選擇題。
沿用共用樣式與測驗程式，並更新首頁及 README.md。
完成後依照 AGENTS.md 的檢查清單確認功能。

## 規則如何幫助延伸
AGENTS.md 明確規定頁面結構、檔案位置、命名方式、
題目資料格式及完成前的檢查項目。
AI 新增內容時可以沿用既有版型，
只需替換學習內容和題目資料，
不必重新設計整個網站或重寫測驗功能。
